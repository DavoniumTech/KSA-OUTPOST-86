# KSA OUTPOST 86 — v2.3.1 usability update

## Purpose

This update addresses first-use confusion and application navigation after the v2.3.0 deployment. It does not claim to add free-roaming astronaut movement. The experience remains a command-and-management training simulator.

## Changes

- Top application bar now spans the full viewport, is fixed to the top edge and uses a clearer full-width app-shell treatment.
- Bottom navigation now spans the full viewport, is fixed to the bottom edge, and gives every destination a larger, more legible touch target and active indicator.
- Added a persistent **How to Play** action in the top bar and home screen.
- Added a player handbook with the real current controls and seven-day Mars objective plan.
- Mission selection now opens a pre-flight briefing before starting the journey.
- Added a first-task explanation and controls briefing before launch.
- Added **START HERE** instructions to the Outpost screen.
- Mars Day 6 now reveals the sample-collection action only after the rover has been deployed.
- Preserved the existing deterministic lunar and Mars simulation systems, local saves, Mission Control helper, Lander Lab, audio, PWA and deployment configuration.

## Current control disclosure

The 3D scene supports camera orbit and zoom, and the Explore screen provides limited rover left/right controls. This release does not yet contain a free-roaming astronaut WASD controller or E-to-interact world stations. The in-app guide now states this explicitly so players are not given controls that do not exist.
