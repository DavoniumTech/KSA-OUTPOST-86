# KSA OUTPOST 86 — V3.7 implementation notes

## Delivered in this source update

- Adaptive navigation: full desktop mission sidebar at 1024px and above, compact tablet rail from 761px through 1023px, and the existing safe-area-aware phone bottom dock at 760px and below.
- Thumb control: joystick displacement is calculated from the live control dimensions; unrelated pointer-up events no longer stop the active joystick; cancellation, lost pointer capture, hidden tabs and window blur reset safely.
- Lunar surface: extra shallow impact features and locally bundled WebP albedo, normal and roughness maps. These maps are loaded only when the lunar terrain is built.
- Oxygen station: two pressure tanks, collars, manifold, valve and illuminated bands are added to the existing Babylon.js terminal.
- Onboarding: Skip is visible at the top on phone sizes, the final CTA reads Start Exploring, and mobile onboarding is constrained to the screen rather than scrolling.

## Validation

Run `npm ci`, `npm run typecheck`, `npm test` and `npm run build` with Node.js 22.16 or newer. A source archive is not a substitute for physical-device touch testing.
