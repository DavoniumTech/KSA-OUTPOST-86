KSA OUTPOST 86 — VERSION 3.0.0
ORBITAL FRONTIER: THE NEXT GENERATION PLANETARY ADVENTURE GAME

Repository: https://github.com/DavoniumTech/KSA-OUTPOST-86.git
Target branch: main

Version 3 includes:
- Three-step 3D onboarding: Meet Your Crew, Choose Your Planet, Learn to Command.
- Earth, Moon and Mars planetary environments.
- Babylon.js 9.35.0 via bundled npm dependency.
- WebGPU preference, WebGL 2 fallback and Canvas fallback.
- Third-person astronaut keyboard and mobile joystick controls.
- Habitat entry and proximity-based station interactions.
- Oxygen, solar-array and greenhouse interaction challenges.
- Rover boarding, driving and proximity-based sample scanning.
- Commander XP, persistent achievement badges and mission reward feedback.
- Light Explorer, Dark Cosmos and Glass Blue themes.
- Guest mode, account UI and Cloudflare Worker account/save/live-event API.
- Existing lunar and Mars mission logic, local saves, Mission Control, audio and Lunar Lander Lab retained.

Build: npm ci; npm run typecheck; npm test; npm run build

IMPORTANT SERVICE REQUIREMENTS:
The account, server-save and WebSocket services require the Cloudflare Worker deployment and its Durable Object bindings. Add CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID to GitHub Actions repository secrets to enable the optional Cloudflare deployment job. Browser alerts are supported while the tab is in the background; closed-browser Web Push is not implemented. Email verification and email-based password reset are not implemented in this release.

This is an independent educational simulation and is not endorsed or certified by NASA. Terrain and 3D assets are procedural game assets unless an explicit source and licence are listed in the asset credits.
