KSA OUTPOST 86 — VERSION 3.5.0
ORBITAL FRONTIER: PREMIUM INTERACTIVE SPACE ADVENTURE

Repository: https://github.com/DavoniumTech/KSA-OUTPOST-86.git
Target branch: main

V3.5 player-experience updates:
- New once-per-player V3.5 tutorial key; old tutorial completion no longer skips the hands-on flow.
- App shell renders before the dynamically imported Babylon.js engine chunk.
- Compact/mobile devices default to the Performance graphics profile.
- Solar-system star/orbit geometry is reduced on Performance mode.
- Avoids the duplicate solar-system rebuild during initial renderer hand-off.
- Stops the GPU render loop while the app is paused or the browser tab is hidden.
- Adds a one-tap 5-minute Mars demo that prebuilds the standard rocket.
- Keeps the full 3D Earth, Moon and Mars scenes, rocket launch, third-person controls, habitat interactions, rover and seven-day mission loops.
- Crew manifest: Amara Okafor, Muhammad Imran, Shuaib and Jafar.
- Fixed full-width header and navigation; larger mobile typography and onboarding viewport.
- Existing lunar/Mars mission logic, saves, Mission Control, audio and Lunar Lander Lab retained.

Commands: npm ci; npm run typecheck; npm test; npm run build

The account, cloud-save and live-session services require the Cloudflare Worker deployment and Durable Object bindings. Add CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID as GitHub Actions repository secrets for the optional Cloudflare deployment job. Browser notifications are supported while the tab is in the background; closed-browser Web Push, email verification and email-based password reset are not implemented.

This is an independent educational simulation and is not endorsed or certified by NASA. Terrain and spacecraft visuals are procedural game assets unless an explicit source and licence are listed in the asset credits.
